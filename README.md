# Fuzul Planım v2

Android için yerel çalışan kişisel finans + Fuzul takip uygulaması.

## Temel özellikler
- Excel bütçe içe aktarma: `SABIT_GİDER`, `Taksit Takibi`, `Aylık Plan`, `FUZUL_SOZLESME`, `Tüm İşlemler`
- Sabit gider ekleme/düzenleme/silme ve plan farkına otomatik yansıtma
- Kredi kartları ve taksit takibi
- PDF/XLSX/CSV ekstre ve hesap hareketi içe aktarma, önizleme ve kategori tahmini
- Vadeli hesap / nakit / altın / diğer varlık takibi
- Fuzul sözleşmesi, ödeme takvimi, tahsisat ve araç fiyat farkı hesabı
- 24 aylık plan ve raporlar
- Yerel JSON yedekleme / geri yükleme

## Gizlilik
Uygulamada internet izni yoktur. Finans verileri cihazdaki Room veritabanında tutulur.
Kişisel finans verileri bu repoya gömülü değildir.
